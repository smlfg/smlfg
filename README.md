# Samuel Fleig

AI Engineering student. I build Human-Agent Interfaces (HAI): systems that let
people work with AI agents without giving away ownership.

**Start here**
- [hai-mcp](https://github.com/smlfg/hai-mcp): MCP control plane with mission contracts, owner gates and evidence-based completion
- [HAI-skills-registry](https://github.com/smlfg/HAI-skills-registry): reusable agent skills, one per folder, with examples
- [variance-workflow](https://github.com/smlfg/variance-workflow): several models build parallel variants instead of one winner
- [ilias-cli](https://github.com/smlfg/ilias-cli): agent-ready CLI for my university's ILIAS, used daily

**How I build:** many agents and models in parallel, small testable slices,
humans approve the decisions.
